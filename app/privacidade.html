Sobre os dados desta demonstração

Este projeto apresenta uma clínica fictícia. Não oferece consultas nem atendimento de saúde. Use apenas nome e telefone fictícios para experimentar o formulário.

O sistema armazena nome, telefone, data e período de preferência, autorização de envio, protocolo, status e histórico. O acesso aos registros exige a senha administrativa. Não envie diagnósticos, prontuários, documentos ou informações sensíveis.

Os eventos enviados ao n8n contêm somente identificadores, status, tipo do evento e data. Nome e telefone não são enviados pelo webhook. O acesso administrativo utiliza um cookie de sessão protegido, com validade de oito horas.

Os dados de teste permanecem no banco até a responsável removê-los. Para pedir exclusão, contate a responsável pelo projeto pelo perfil público no GitHub, informando apenas seu protocolo, sem publicar dados pessoais.

Perfil da responsável pelo projeto

Antes de utilizar este sistema numa clínica real, é necessário definir responsáveis, retenção dos dados, atendimento ao titular, contas individuais da equipe e controles adequados à operação.
